# Design: страница услуги «SEO для B2B»

Дата: 2026-08-17  
Статус: по аналогии с соседними SEO-элементами раздела

## Цель

Создать посадочную страницу услуги в инфоблоке «Услуги» по дизайн-модели `.dm-page`, перенеся контент из standalone-файла `SEO для B2B.html` без изменения текстов. Элемент — в уже существующем разделе «SEO продвижение».

## Контекст

- Ветка `feature/seo-korporativnyy-sayt`, эталон `uslugi-seo-prodvizhenie-sayt-dlya-nedvizhimosti.html`, CSS `design-model.css`.
- `DETAIL_TEXT` элемента iblock 21; HTML в `design-model/pages/`.
- Раздел `seo-prodvizhenie` (ID **159**) уже есть.
- Правила — **аналогичны** предыдущим SEO-элементам раздела.

## Решения (зафиксировано с заказчиком)

| Тема | Решение |
|---|---|
| Раздел | `seo-prodvizhenie` (159) |
| Элемент | NAME «SEO для B2B под ключ», CODE `seo-dlya-b2b` |
| URL | `/services/seo-prodvizhenie/seo-dlya-b2b/` |
| Meta | из `<head>` через `IPROPERTY_TEMPLATES` |
| Тексты | дословно; опечатку «доподнительная» исправить на «дополнительная» |
| Иконки | SVG, без эмодзи |
| CTA | H2+lead + CALLBACK; без формы/телефонов |
| CSS | новый не требуется |
| «1С» | оставлять как в исходнике (`1С-Битрикс`) |

**Meta:**
- Title: `SEO для B2B под ключ — продвижение B2B-сайтов | ITWEB`
- Description: `SEO-продвижение B2B-сайтов, корпоративных порталов, оптовых компаний под ключ. Контент-маркетинг, экспертные статьи, работа с длинными сделками. От 40 000 ₽/мес. Бесплатный аудит.`

## Архитектура доставки

1. Файл: `bitrix/templates/aspro_max/design-model/pages/uslugi-seo-prodvizhenie-dlya-b2b.html`
2. Элемент в iblock 21 / секция 159, `DETAIL_TEXT` = HTML, ACTIVE=Y
3. Staging sync (`scripts/dm-sync-page.sh --env remote --code seo-dlya-b2b`); commit/push по «задеплой»

## Порядок секций

1. Hero (benefits: 50+ B2B-проектов, Рост корпоративных заявок, Результат за 3-6 мес, Гарантия 12 месяцев)
2. Что мы делаем — Техническое SEO / Контент и экспертность / Репутация и ссылки
3. Почему выбирают (в т.ч. «Фокус на длинные сделки»)
4. Кейсы (`#dm-cases`) — производитель / опт / B2B-услуги
5. Тарифы — 40 000 / 80 000 (featured) / 140 000 ₽/мес
6. Доп. услуги (URL из исходника без изменения)
7. Этапы (6 шагов; эмодзи-префиксы не переносить)
8. Инструменты (8×, 8-й Text.ru / Advego)
9. Отзывы (Константин / Дарья / Сергей)
10. FAQ (8)
11. CTA без формы
