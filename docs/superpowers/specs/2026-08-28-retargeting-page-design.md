# Design: страница услуги «Настройка ретаргетинга»

Дата: 2026-08-28  
Статус: элемент в разделе «Контекстная реклама»

## Цель

Создать посадочную страницу услуги в инфоблоке «Услуги» по дизайн-модели `.dm-page`, перенеся контент из `Ретаргетинг.html` без изменения текстов. Элемент — в разделе `kontekst`.

## Контекст

- Ветка `feature/seo-korporativnyy-sayt`, эталон `uslugi-kontekst-rsya.html`, CSS `design-model.css`.
- `DETAIL_TEXT` элемента iblock 21; HTML в `design-model/pages/`.
- Раздел `kontekst` уже есть (см. manifest).

## Решения

| Тема | Решение |
|---|---|
| Раздел | `kontekst` |
| Элемент | NAME «Настройка ретаргетинга под ключ», CODE `retargeting` |
| URL | `/services/kontekst/retargeting/` |
| Meta | из `<head>` через `IPROPERTY_TEMPLATES` |
| Тексты | дословно |
| Иконки | SVG, без эмодзи |
| CTA | H2+lead + CALLBACK; без формы/телефонов |
| CSS | новый не требуется |
| Ссылки | как в исходнике: `/uslugi/prodvizhenie/kontekst/...` |

**Meta:**
- Title: `Настройка ретаргетинга под ключ | ITWEB`
- Description: `Настройка ретаргетинга под ключ в Яндекс.Директ. Возвращаем до 20% клиентов, которые ушли без заявки. Сегменты по поведению, динамический ретаргетинг. От 15 000 ₽.`

1. Hero
2. Что входит (3 карточки)
